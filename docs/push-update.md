# Напоминания и личная панель

Палитра, шрифт и фокус сохраняют существующий стиль CaloriSnap. Панель выравнивается
слева: получатель → выбор действия → текст → предпросмотр → отправка. Без новых библиотек
и фоновых анимаций; два столбца действий помещаются на телефоне. Действия пользователя
не маскируются под фактическую доставку: показывается подтверждение push-сервиса.

## Расписание
11:00, 15:00, 19:00 по IANA timezone подписки. Дополнительное в 20:30 с вероятностью
50% за пользователь-день; SHA-256 делает решение одинаковым на всех устройствах и
повторных запусках. Cron каждые 15 минут; возможны задержки платформы, окно догоняющей
отправки 2 часа. Не обещаем точность будильника.

В существующем TEXT last_message сохраняется JSON {date,slots,history}; старые строковые
значения читаются совместимо. История последних 12 текстов запрещает точные повторы.
CAS по updated_at предотвращает одновременную отправку одной подписке. Ошибка отправки
откатывает запись слота. Аварийное завершение после claim может пропустить один слот;
exactly-once доставка через внешний push-сервис недостижима без подтверждений телефона.
За запуск обслуживаются 10 подписок из-за 30-секундного лимита scheduled functions.

## ИИ
Groq создаёт ласковое сообщение Даше. При таймауте — случайная комбинация из 192
резервных текстов без повторения недавних. Абсолютная уникальность навсегда не гарантируется.

## Админка
/admin, пароль только ADMIN_PASSWORD на сервере; подписанная HttpOnly SameSite cookie
на час с отдельным случайным ADMIN_SESSION_SECRET. Same-origin POST; разрешён только
CAL-SZT7-KK3Z. Нет чтения питания, редактирования чужих записей или произвольных URL.
Ссылка ведёт в выбранный раздел; iOS может скрывать кнопки push.

Пароль dasha слабый и известен участникам переписки. Ограничитель попыток в памяти
не является распределённой защитой при масштабировании serverless. Перед расширением
админки нужен длинный пароль/аккаунт администратора и постоянный rate limiter.

Подписка возможна только с разрешением получателя. iPhone требует PWA на экране Домой.
Реальную доставку и поведение конкретного iPhone необходимо подтвердить на устройстве.
