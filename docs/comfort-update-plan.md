# CaloriSnap: обновление удобства (ожидает разрешения на публикацию)

## Цель
Быстрее находить действие, меньше прокручивать, не доверять устаревшим расчётам.
Не менять авторизацию, питание, пользовательскую палитру или структуру базы ради дизайна.

## План и критерии
1. Хаб: инструменты первыми; внешность, достижения и эксперименты свернуть.
   Калькулятор, продукты и тренировки доступны прямыми ссылками.
2. Каталог тренажёров: поиск с ё/е, опечатками, синонимами и английскими названиями;
   показать количество результатов и понятный сброс поиска. Без запросов к ИИ.
3. Расчёт тренировок: после изменения веса/подходов использовать актуальный локальный
   калькулятор, не сохранённый старый ответ ИИ. Противовес гравитрона не считать нагрузкой.
4. Мобильный комфорт: не качать карточки во время скролла на сенсорных устройствах;
   уважать reduced-motion. Диалоги: Escape, удержание фокуса, блокировка фонового скролла.
5. Проверки: lint, TypeScript, весь набор тестов, production build; интерфейс на узком экране.

## Дизайн
Сохранить выбранные пользователем CSS-переменные: фон #f2f2f7, поверхность #fff,
текст #1c1c1c, зелёный #34c759, предупреждение #ff9500 (только исходные значения).
Сохранить существующий шрифт, левое выравнивание, понятную иерархию вместо декоративных
подписей. Наиболее заметны действия; настройки выглядят спокойнее и раскрываются по желанию.

Хаб: заголовок → быстрые действия → полезные ссылки → статистика → дополнительные секции.
Каталог: заголовок → поиск → категории → результаты → настройка выбранного упражнения.

## Ограничения
Ни один калькулятор не измеряет реальный расход: особенно силовые калории приблизительны.
Не менять сторонние/предыдущие правки. Не публиковать это обновление без разрешения.
Проверка фактической доставки push требует подписки на телефоне и разрешения iOS.

## Skill
Используется проверенный instruction-only frontend-design из anthropics/skills.
Он влияет на иерархию, спокойную анимацию и ясные названия; не добавляет библиотеки в сайт.
